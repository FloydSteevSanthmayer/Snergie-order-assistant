# Contributing

Thank you for your interest in contributing to SYNERGIE Order Assistant.

Author: Floyd Steev Santhmayer

Please follow these steps for contributions:
1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Write tests and ensure existing tests pass.
4. Submit a pull request describing your changes.

Code style: Black + isort + flake8. Run `pre-commit` hooks before committing.
